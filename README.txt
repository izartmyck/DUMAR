WEBSITE PROFIL DUSUN DUMAR - TEMA BIRU

Isi folder:
- index.html : struktur dan konten website
- style.css  : tampilan, warna, layout responsif
- script.js  : menu mobile, tanggal, dan animasi angka
- assets/    : foto balai dusun dan galeri Suasana Desa

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder website_profil_desa_biru.
3. Klik dua kali index.html, atau buka folder dengan VS Code lalu jalankan memakai ekstensi Live Server.

PENTING:
Website ini memakai nama Dusun Dumar. Beberapa data (jumlah warga, KK, fasilitas,
alamat, telepon, dan email) masih berupa contoh dan perlu diperiksa sebelum dipublikasikan.
Foto balai dusun, suasana, potensi perikanan, sekolah, dan poskesdes tersimpan lokal di folder assets.
